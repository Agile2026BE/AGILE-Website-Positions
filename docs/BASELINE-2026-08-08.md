# AGILE Careers Approved Baseline — August 8, 2026

This file records the approved functionality baseline for the AGILE Careers experience. Do not remove or replace these behaviors without explicit approval.

## Primary navigation
- AGILE logo/home navigation must provide a reliable way back to the top/home experience.
- Positions must navigate to the position search section.
- Why AGILE and Reviews must navigate to their corresponding sections.
- Contact must navigate to the Start a Conversation section.
- Search Careers must navigate to the position search section.

## Hero
- Primary button: Search Careers.
- Secondary button: Start a Conversation.
- Trust badges include visible check marks: Salary disclosed, Location disclosed, Work schedule disclosed, No account required.

## Position cards
- Position cards remain white against the softer page background.
- Save terminology is replaced by + Shortlist.
- View Position opens the position details modal.
- Shortlist supports up to three selected opportunities.

## Position details modal
- Position title must be proportionate and not oversized.
- Full position details remain scrollable.
- Similar Positions remain available.
- Bottom actions are exactly: I’m Interested and Share Position.
- Do not use the operating system native share sheet from this modal.

## I’m Interested sequence
1. Candidate opens View Position.
2. Candidate reviews the position modal.
3. Candidate clicks I’m Interested.
4. Open the in-app Start a professional conversation modal.
5. The modal carries the selected position title and ID.
6. Form fields: Name, Email, Phone, Quick Message, editable Message, optional Resume.
7. Send My Inquiry submits through /api/inquiry.

This in-app modal is the approved behavior. Do not replace it with a jump that leaves the candidate guessing where the form went.

## Share Position sequence
1. Candidate clicks Share Position.
2. Ensure that position is in the shortlist.
3. Open the in-app Share selected positions panel.
4. Show selected opportunities and allow removal.
5. Copy for Email creates a clean text block for each selected position in this format:

Associate Electrical Engineer – Power Systems and Modeling

NYC, NY · Hybrid Schedule

$122,000–$140,000+ · ID 1002

View Position: https://careers.agileconsultingsolutions.com/p/1002

6. Inquire About These opens the Start a professional conversation form.
7. Do not invoke navigator.share / the native macOS share sheet.

## Wording locked during functionality phase
- + Shortlist
- Start a Conversation / Start a professional conversation
- Professional Career Consultants

Word polishing can happen later. Functionality and navigation take priority.
