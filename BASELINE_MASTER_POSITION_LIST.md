## Purpose

This workbook is the required baseline for all current and future AGILE position records. Every new position must follow the existing workbook structure, field definitions, formatting conventions, Position ID rules, SEO fields, and publishing workflow.

## Locked Structure Rules

1. Preserve the existing `Master Positions` column names, column order, field meaning, and data conventions.
2. Never reuse a Position ID.
3. Add every new position as a new row using the same field structure.
4. Preserve historical positions by changing Status instead of deleting records.
5. Complete the SEO Slug, SEO Title, Meta Description, Direct URL, and all other required publishing fields before publication.
6. Preserve the complete approved website description and structured sections so no position detail is lost.
7. Use the existing `Data Quality` and `Publishing Guide` workflows as validation standards.
8. Do not redesign, rename, normalize, consolidate, reorder, or remove workbook fields unless Byron Evans gives an explicit current instruction to change the master format.
9. The workbook is intended to scale from the current inventory to 200–250+ active positions without changing the baseline schema.
10. Any website publishing logic must be checked against this baseline before structural changes are made.
